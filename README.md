# Íslenskukennsla ⚡ Платформа вивчення ісландської мови для українців (A1–B2)

Сучасна інтерактивна навчальна веб-платформа для україномовних студентів, створена за академічними стандартами **Árnastofnun**, **Bara tala**, **Drops** та **Ylhýra**.

---

## 🌟 Основні можливості

- **100% україномовний UI Chrome**: Інтуїтивне пояснення ісландської граматики, мнемонік та фонетичних явищ українською мовою.
- **Модуль 0 (Stafrófið & Framburður)**:
  1. *Абеткова матриця*: 32 літери з автентичною ісландською вимовою та мнемонічними асоціаціями.
  2. *Голосні та дифтонги (Raddstafir)*: 6 чистих монофтонгів, 6 дифтонгів та 6 пар трансформації через broddur (знак наголосу).
  3. *Фонетичні пастки (Bara tala)*: Преаспірація, латеральний вибух, дентальні фрикативи, 4 стани літери G.
  4. *Аудіодуель*: Тренажер мінімальних розрізнень звуків у сліпому режимі.
  5. *IPA Конструктор слів*: Збирання фонетичної транскрипції слів.
  6. *Симулятор діалогу (Jón & Anna)*: Живий месенджер-діалог із перемиканням ролей (Karlkyn / Kvenkyn) та правилами етикету.
  7. *Інтерактивний тренажер*: 10 тестових запитань із аудіо-підказками.
- **Модуль 1 (Kafli 1: Hver ert þú?)**:
  - Drops Flexion Lab (лабораторія відмінювання іменників та прикметників).
  - Вера Грамматик Хаб (дієслово *að vera*).
  - Словниковий запас та ситуативні діалоги.
- **BÍN Aura System**: Інтелектуальна підсвітка відмінків ісландської мови (Nf., Þf., Þgf., Ef.).
- **Локальний ШІ-Тьютор**: Інтеграція з локальною мовною моделлю (LM Studio, `localhost:1235`).

## 🚀 Швидкий запуск

### Локально:
```bash
git clone https://github.com/tfmshell-cloud/islenskukennsla.git
cd islenskukennsla
python3 -m http.server 8000
```
Відкрийте у браузері: [http://localhost:8000/index.html](http://localhost:8000/index.html)
